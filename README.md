# ltx-voice-library

Designed voices for `usamaehsan/ltx-voice-lock-test` (`voice_id` input).

Every clip here was generated by our own LTX voice model from a written voice
description (the prompt and seed are in each json). None is a recording of a
real person.

Layout: `voices/<id>.wav` (2-8 s, stereo 16-bit) + `voices/<id>.json`
(`transcript`, `lang`, `prompt`, `seed`, `model`). Adding a voice = adding these
two files; the model needs no rebuild.
